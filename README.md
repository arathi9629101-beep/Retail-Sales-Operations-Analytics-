# Retail Sales Operations Analytics

## Project Overview
This project analyzes retail sales operations using
Microsoft Excel.

- PivotTables
- Excel Formulas

- Data Visualization

## Project Features

- Advanced Excel Functions

- Total Order Value

- Total Order Records
